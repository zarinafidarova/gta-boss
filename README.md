# Grand Heist: Monte-Carlo

Комикс без слов для https://gta.sometests.ru в стиле экранов загрузки GTA: один день на Лазурном берегу. Утро на вилле, сборы, серпантин, казино Монте-Карло, выигрыш в рулетку, уход от охраны и полиции, катер и финал на яхте.

После «mission passed» идёт вторая миссия, «Grand Prix»: через неделю он садится за руль ретро-болида номер 7 вместо заболевшего пилота. Паддок, экипировка, старт со светофором, обгон у гавани, туннель, шпилька, финиш и подиум.

Историю рассказывает интерфейс игры: часы идут от утра к закату, небо за страницей меняет цвет, на радаре едет метка по маршруту, деньги растут после рулетки, звёзды розыска загораются и гаснут, в конце появляется «mission passed».

Чистые HTML/CSS/JavaScript без сборки. Шрифты подгружаются с Google Fonts, плавный скролл (Lenis) с jsDelivr. Изображения хранятся локально в WebP.

## Запуск

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:8766.

## Файлы

- `site/index.html` — последовательность сцен, карточки миссий, описания кадров для экранных дикторов.
- `site/style.css` — оформление, интерфейс игры, анимации.
- `site/main.js` — привязка сцен к прокрутке, камера в закреплённых сценах (`cams`), часы, деньги, розыск, радар, частицы, кнопка шампанского.
- `site/assets/grandprix/` — кадры второй миссии: `cover`, `paddock`, `gear`, `grid`, `harbor`, `tunnel`, `hairpin`, `finish`, `podium`.
- `site/assets/riviera/` — кадры первой миссии, уменьшенные версии вертикальных кадров и `og.jpg` для превью ссылки.
- `deploy/nginx/gta.sometests.ru.conf` — конфигурация nginx.

## Размещение

Настроить DNS A/AAAA домена на нужный сервер. Скопировать репозиторий в `/var/www/gta-boss` (или изменить root в nginx-конфигурации). Для HTTPS нужен сертификат домена.

```sh
sudo cp deploy/nginx/gta.sometests.ru.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/gta.sometests.ru.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d gta.sometests.ru
```

Если сервер использует conf.d, скопировать конфигурацию туда вместо sites-available. Не создавать повторную конфигурацию при существующем server_name.

Репозиторий локальный. Удалённый Git remote, DNS и сервер автоматически не изменяются. Для будущих обновлений из настроенного remote: `bash deploy/update.sh`.

## Изображения

Иллюстрации сгенерированы пользователем по промптам. Порядок кадров: `cover`, `villa`, `prep`, `drive`, `arrival`, `roulette`, `exit`, `boat`, `yacht`. Чтобы поменять, куда смотрит камера в закреплённой сцене, правьте точки в `cams` в `site/main.js`: `x` и `y` — точка картинки в центре экрана (доли от 0 до 1), `z` — приближение.
