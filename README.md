# Босс района

Немой неоновый сайт-комикс для https://gta.sometests.ru. Чистые HTML/CSS/JavaScript, без зависимостей, внешних шрифтов, аналитики и сборки. Все изображения хранятся локально в WebP.

## Запуск

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:8766. На телефоне нативная прокрутка. Закреплённые сцены связывают движение камеры с прокруткой, отдельный canvas рисует частицы и дождь. Кнопка паузы отключает движение; системный prefers-reduced-motion поддерживается. В финале можно нажать лапку. История остаётся доступной без JavaScript.

## Файлы

- `site/index.html` — последовательность кадров и описания для экранных дикторов.
- `site/style.css` — композиция панелей, неон и адаптация.
- `site/main.js` — прокрутка, атмосфера, пауза, интерактивный финал.
- `site/assets/` — пользовательские иллюстрации, версии для небольших экранов и превью ссылки.
- `deploy/nginx/gta.sometests.ru.conf` — конфигурация nginx.

## Размещение

Настроить DNS A/AAAA домена на нужный сервер. Скопировать репозиторий в `/var/www/gta-boss` (или изменить root в nginx-конфигурации). Для HTTPS нужен сертификат домена.

```sh
sudo cp deploy/nginx/gta.sometests.ru.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/gta.sometests.ru.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d gta.sometests.ru
```

Если сервер использует conf.d, скопировать конфигурацию туда вместо sites-available. Не создавать повторную конфигурацию при существующем server_name.

Репозиторий локальный. Удалённый Git remote, DNS и сервер автоматически не изменяются. Для будущих обновлений из настроенного remote: `bash deploy/update.sh`.

## Изображения

Иллюстрации предоставлены пользователем. Веб-версии оптимизированы без генерации новых картинок. Листы персонажей не входят в историю. История содержит 15 сюжетных кадров и отдельную обложку. Финальная сцена — мужчина за рулём, кот на его куртке на заднем сиденье.
